# (скобки) — концептуальный лендинг

Статический прототип на HTML, CSS и JavaScript. Без сборки и зависимостей.

## Запуск
Откройте `index.html` в браузере, либо в терминале из этой папки запустите `python -m http.server 8000` и перейдите на http://localhost:8000.

## GitHub Pages
Загрузите **содержимое папки** в корень репозитория. В Settings → Pages выберите Deploy from a branch → main → /(root).

## Важно перед запуском продаж
- Изображения являются концептуальными мокапами, окончательные продукты и UGC нужно заменить.
- Подбор набора демонстрационный и не является медицинской рекомендацией.
- Не реализованы реальная корзина, оплата, заказ или заявки.
- Логотип сейчас набран стилизованным текстом. Для точного совпадения с фирменным знаком замените его утверждённым SVG из Figma.
- Названия, содержимое набора, свойства продуктов и юридические сведения следует сверить с фактическим ассортиментом.
